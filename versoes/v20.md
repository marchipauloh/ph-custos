# v20 — Exportação Excel (.xlsx)

## O que mudou

A V20 é a V19 + **uma única coisa**: exportação para planilha.

1. Botão "Excel (.xlsx)" verde no painel financeiro
2. Planilha com 7 abas: Propostas, Itens, Gastos, Equipe, Parcelas,
   Cronograma e Leia-me
3. **Fórmulas vivas**: recebido, gastos e resultado são `SUMIFS` que
   somam as outras abas. Editar um gasto dentro do Excel atualiza os
   totais da aba Propostas
4. Gerador de `.xlsx` escrito do zero (ZIP + CRC32 + XML do Office),
   sem nenhuma biblioteca externa
5. Botões renomeados: "Exportar backup" → "Backup (.json)" e
   "Importar" → "Importar backup", com o tooltip explicando que só
   o `.json` volta para o sistema
6. Refactor interno: `exportarBackup` passou a usar a função
   `baixarArquivo()` que o Excel criou (tira código duplicado)

## Como foi validado

- CRC32 conferido contra o valor conhecido `0xCBF43926`
- ZIP aberto pelo próprio Windows (12 partes)
- Os 12 XMLs validados com `XmlDocument.LoadXml`
- A planilha foi **aberta no Excel de verdade** via COM, e a linha da
  proposta 1 conferiu: `R$ 37.169,09` orçado, `R$ 32.320,95`
  executado, resultado `R$ 6.610,10`

## Importante

A V20 perdeu todas as correções da v21 (hotel, etapa por índice,
validação de backup, debounce, `localStorage` com `try/catch`,
acessibilidade). Ela é **funcionalmente inferior** à nossa v21+.

O original está guardado em `testes/PH_projetos.V20-original.html`
para comparação.
