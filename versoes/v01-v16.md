# v1 a v16 — Antes de documentar

Não há registro detalhado destas versões: até a v16 o projeto era um
único arquivo HTML e nenhuma mudança era anotada.

O que é possível reconstruir a partir do código:

| Versão | Marca visível no código | O que trouxe |
|---|---|---|
| v1 | — | Formulário de orçamento inicial |
| v2–v5 | — | Cálculo de materiais e equipe |
| v6–v10 | — | Cronograma e parcelas |
| v11–v14 | — | Painel financeiro e histórico |
| v15 | migração `versao: 15` | Estrutura do backup mudou |
| v16 | migração `versao: 16` | Reserva passou a ter campo próprio |

## Ponto importante

A migração para v15/v16 está no código (`normalizarProjeto`), dentro de
`js/02-regras.js`. Ela roda **sempre** que um backup é importado, então
backups antigos continuam abrindo — mesmo hoje, na v24.

**Se você for criar a v25+, não apague essas migrações.** Um backup de 2024
precisa continuar abrindo.
