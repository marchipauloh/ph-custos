# v27 - Remocao das pastas oficiais

## O que mudou

Saiu do painel financeiro a interface de "pastas oficiais". Antes eram 7
botoes; agora sao 5.

### Antes

| # | Botao | O que fazia |
|---|---|---|
| 1 | Backup | gravava na pasta oficial de .json |
| 2 | Salvar no PC | pasta oficial + janela "Salvar como" |
| 3 | Excel | gravava na pasta oficial de .xlsx |
| 4 | Salvar no PC | pasta oficial + janela "Salvar como" |
| 5 | Importar backup | abria o .json |
| 6 | **Pasta de backups** | apontava a pasta de .json |
| 7 | **Pasta de planilhas** | apontava a pasta de .xlsx |

Debaixo dos botoes havia uma linha de status:
`Backup: C:\PH_Backups | Planilha: sem pasta`

### Depois

| # | Botao | O que faz |
|---|---|---|
| 1 | Backup | baixa o .json para Downloads |
| 2 | Salvar no PC | abre a janela do Windows para escolher |
| 3 | Excel | baixa o .xlsx para Downloads |
| 4 | Salvar no PC | abre a janela do Windows para escolher |
| 5 | Importar backup | abre o .json |

## Por que remover

O conceito de "pasta oficial" nao ajuda quem so quer salvar um arquivo.
Pior: no servidor, cada usuario teria que apontar uma pasta do **PC
dele**, o que e contra-intuitivo (o endereco e do servidor, nao dele).

Comportamento padrao de qualquer sistema web: **o arquivo vai para
Downloads**, com data, hora, minuto e o nome do cliente. Quem quiser outro
lugar usa "Salvar no PC".

## Consequencia a conhecer

**Nao existe mais backup automatico.** Antes, cada "Salvar proposta"
gravava um .json na pasta oficial. Agora o backup e so pelo botao.

Como os dados vivem no `localStorage` do navegador, isso significa:
**limpar o cache do Chrome continua apagando tudo.** Mitigacao: clicar em
"Backup" de vez em quando.

Se quiser automatizar de novo sem voltar a interface, o caminho e um
servidor (a gravacao viraria um POST). Com `localStorage` nao ha como
gravar em disco sem o usuario pedir.
