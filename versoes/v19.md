## Bugs reais que viviam aqui (achados depois, na v21)

Dois bugs de precificação ficaram escondidos até a v21:

### 1. O hotel nunca era zerado

O campo "Pessoas" no hotel dizia no rótulo que zerava o custo quando
fosse 0, mas a fórmula não fazia isso:

```js
// ERRADO (v19 e v20)
const totalHotel = hotelDias * hotelPess * (hotelV / (hotelPess || 1));
// isso se simplifica para hotelDias * hotelV  -- o "pessoas" não influencia nada
```

### 2. O carro tinha "Km x2" no rótulo e `* 1` na conta

O campo prometia dobrar a distância, mas o cálculo não dobrava:

```js
const totalCarro = carroKm * 1 + carroPed;
```

## Como a v21 resolveu

- Hotel: `hotelPess > 0 ? hotelDias * hotelV : 0` — agora 0 pessoas
  realmente zera o custo
- Carro: o campo passou a significar **Km total**, e o rótulo foi
  corrigido para "Km total" (não inventei a dobra; deixei a fórmula
  original e arrumei o texto que mentia)

**Se a intenção original era mesmo dobrar** (240 km de ida = 480 total),
o ajuste é em `calcular()`: trocar `carroKm * 1` por `carroKm * 2`.
