# v23 — index.html e pastas de backup

## O que mudou

### 1. index.html como porta de entrada

`index.html` redireciona para a Aba 1 em 3 segundos, e traz:
- Botão laranja grande para a Aba 1
- Os 4 cards de abas, com o que cada uma faz
- Três avisos que resolvem a maioria das dúvidas de quem abre pela
  primeira vez

### 2. Pastas de backup separadas

Duas pastas independentes, escolhidas uma vez cada:

- **Pasta de backups** (`.json`)
- **Pasta de planilhas** (`.xlsx`)

Separei em duas para quem precisar conferir um backup daqui a cinco
anos não ter que garimpar planilha junto.

**Duas vias de exportação:**
- **Backup** / **Excel** → gravam **só** na pasta oficial, em silêncio
- **Salvar no PC** → grava na oficial **e** abre o "Salvar como"

### 3. Backup automático ao salvar proposta

Cada vez que uma proposta é salva, o `.json` vai sozinho para a pasta
oficial. Só acontece se a pasta estiver configurada.

Motivo: a pergunta depois de "Salvar" é sempre *"e agora, onde foi
parar?"* — e a resposta passa a aparecer sem precisar lembrar de
exportar.

### 4. Nomes de arquivo

```
ph_custos_backup_Studio-Fronteira-Cia_2026-10-10_22h41.json
ph_custos_planilha_Studio-Fronteira-Cia_2026-10-10_22h41.xlsx
```

Data, hora, minuto e o nome do projeto/cliente. Sem cliente
preenchido, sai só o carimbo.

### 5. Botões renomeados

"Pasta .json" e "Pasta .xlsx" só faziam sentido pra quem já sabia o
que era. Viraram **Pasta de backups** e **Pasta de planilhas**, e
ganharam uma linha de status mostrando o caminho real configurado
(ou "sem pasta", em amarelo).

## Limite do navegador (importante)

`showDirectoryPicker()` é uma API de **contexto seguro**. Ela abre uma
janela do sistema operacional, então exige a aba do navegador **em
destaque** — com a aba em segundo plano, o Chrome recusa.

E a pasta vale **só enquanto o navegador estiver aberto**. Ao fechar e
abrir de novo, clique em "Pasta" de novo. O Windows não devolve essa
permissão de forma confiável (a via IndexedDB volta pedindo autorização
de novo, o que seria pior).

## Arquivo que entra nunca é gravado

Um `.json` **importado** não é gravado na pasta de backups. Um arquivo
adulterado dentro da pasta oficial seria pior do que não ter backup —
ele ficaria parecendo legítimo entre os seus backups reais.

## Validação

| Cenário | Resultado |
|---|---|
| Duas pastas, backup só oficial | grava na `.json`, não baixa |
| Duas pastas, Excel só oficial | grava na `.xlsx`, não baixa |
| "Salvar no PC" | grava na oficial e baixa |
| Só a pasta `.json` + Excel | vai pra Downloads com aviso |
| Backup automático ao salvar | só grava com pasta configurada |
| Regras / páginas / rascunho | 26/26 · 4/4 · 6/6 |
