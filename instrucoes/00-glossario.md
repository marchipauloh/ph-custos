# Glossário

Esta lista define os termos oficiais da documentação.
Use apenas o termo oficial. Não use os termos proibidos.

## Termos oficiais

| Termo oficial | Significado | Termos proibidos |
|---|---|---|
| **Abrir** | Carregar um arquivo ou uma página no navegador | acessar, iniciar, carregar |
| **Clicar** | Acionar um botão ou um link | apertar, pressionar, selecionar |
| **Executar** | Iniciar um comando no terminal | rodar, disparar, lançar, run |
| **Salvar** | Guardar a proposta no navegador | gravar, persistir |
| **Exportar** | Baixar um arquivo com os dados | extrair, descarregar |
| **Importar** | Carregar um backup `.json` no sistema | restaurar via arquivo, subir |
| **Gerar** | Criar um arquivo com um script | montar, produzir, compilar |
| **Editar** | Alterar o conteúdo de um arquivo | mexer, modificar, trocar |
| **Publicar** | Enviar o conteúdo de `public/` ao servidor por FTP | subir, fazer deploy |
| **Proposta** | Documento com custos e prazos de uma obra | orçamento, projeto |
| **Aba** | Uma das 4 páginas do sistema | tela, seção |
| **Backup** | Arquivo `.json` com todos os dados | cópia de segurança, snapshot |
| **Rascunho** | Cópia temporária guardada ao trocar de aba | cache, temporário |
| **Navegador** | Programa que abre o sistema | browser |
| **Orçado** | Valor calculado na proposta | previsto, estimado |
| **Executado** | Soma dos gastos lançados | realizado, gasto real |

## Termos técnicos permitidos

| Termo | Significado |
|---|---|
| **LocalStorage** | Armazenamento do navegador que guarda as propostas |
| **Tailwind** | Biblioteca que fornece as classes de estilo |
| **CSS compilado** | Arquivo `PH_custos_compilado.css` gerado pelo Tailwind |
| **Node** | Programa que executa os scripts de `ferramentas/` |
| **Build** | Etapa que gera o CSS compilado |
| **Console** | Painel de erros do navegador, aberto com **F12** |
| **HTTPS** | Endereço seguro de servidor |
| **FTP** | Protocolo que envia os arquivos de `public/` ao servidor |

## Regras de escrita

- Escreva na voz ativa. Diga quem faz a ação.
- Escreva uma instrução por frase.
- Limite instruções a 20 palavras.
- Limite descrições a 25 palavras.
- Use listas para sequências, condições e pré-requisitos.
- Destaque em **negrito** os botões e as abas.
- Destaque em `código` os arquivos, as pastas e os comandos.
